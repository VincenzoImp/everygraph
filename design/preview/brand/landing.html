Twelve lines, from a file to a map

import everygraph as eg

eg.config(memory="8GB")                  # the budget is a hard limit
g = eg.read("transfers.parquet", src="sender", dst="receiver")

print(g)                                 # 212.4 M nodes · 1.83 B edges
rank = g.pagerank()                      # same answer at any thread count
comm = g.communities()
print(g.explain("communities"))          # the plan and its cost, in words

m = g.map(color=comm, size=rank)         # a zoomable map of everything
m.save("transfers.egmap.html")           # one file; open it anywhere

What happens
  1. You say how much memory it may use.Everything after that is planned to fit.
  2. The file is read once.You get a summary: rows, nodes, duplicates, what was skipped.
  3. Analyses return tables.Arrow, pandas or Polars — whichever you already use.
  4. The map is a file.No server; send it by e-mail or put it on a web page.

When to use something else

Everygraph is for looking at and measuring a big graph on the computer you have. It is not a database, a cluster or a drawing program, and it reads from and writes to the tools that are.

Use Everygraph for
  • more than 10⁸ edges on a workstation or laptop
  • a map from the whole graph down to single nodes
  • a hard memory budget
  • results you can reproduce
Polishing a figure of a few thousand nodesGephi
Transactions, Cypher, many users at onceNeo4j
Questions that are really SQL over tablesDuckDB
Training graph neural networksPyG · DGL
Data that does not fit on one machine's diska cluster framework
